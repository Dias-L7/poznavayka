Позновайка 🌍

Позновайка — әлем елдері туралы білім алуға арналған интерактивті білім беру веб-платформасы.

Жоба мақсаты

Пайдаланушыларға әртүрлі елдердің географиясын, тарихын, мәдениетін және негізгі ерекшеліктерін қызықты әрі қолжетімді түрде үйренуге көмектесу.

Негізгі мүмкіндіктері

- 🌎 Интерактивті әлем картасы
- 🔎 Елдерді іздеу және таңдау
- 🏛️ Елдер туралы ақпарат: астанасы, халқы, аумағы, тілі және валютасы
- 📚 Елдер туралы қызықты деректер
- 🧠 Білімді тексеруге арналған викторина
- 🎯 Әртүрлі қиындық деңгейлері
- ⭐ Таңдаулы елдерді сақтау
- 🌙 Қараңғы режим
- 📱 Телефондар мен компьютерлерге бейімделген дизайн

Қолданылған технологиялар

- HTML5 — веб-беттің құрылымы
- CSS3 — дизайн және бейімделгіш интерфейс
- JavaScript — интерактивті функциялар
- Leaflet — интерактивті карта
- OpenStreetMap — карта деректері
- REST Countries API — елдер туралы ақпарат

Қалай іске қосуға болады?

1. Репозиторийді компьютерге жүктеп алыңыз.
2. Жоба папкасын Visual Studio Code бағдарламасында ашыңыз.
3. "index.html" файлын Live Server көмегімен іске қосыңыз.
4. Интернетке қосылыңыз — сыртқы карта мен елдер деректерін жүктеу үшін қажет.
